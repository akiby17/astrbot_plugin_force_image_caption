# Force Image Caption

为 **DeepSeek 等纯文本主模型** 自动补充图片理解。

用户正常发图即可：

```text
[图片] @机器人 那这张呢
```

插件会自动完成：

```text
图片 → 视觉模型理解 → 文本结果 → 主聊天模型
```

## 特点

- 自动处理当前图片、引用图片和多图
- 视觉模型临时失败时自动重试，重试次数可配置
- 多图整体失败后可逐张恢复
- 空响应也可自动重试
- 全部重试失败后可静默降级，清理 `[Image Captioning Failed]` 等内部失败标记
- 可禁止主模型向用户回复“没看到图片 / 识图失败”，且不编造视觉内容
- AstrBot 已成功生成图片转述时直接复用，避免重复调用

## 推荐设置

纯文本主模型建议保持：

- `转述成功后移除原图`：开启
- `全部重试失败后移除原图`：开启
- `识图失败时静默处理`：开启
- `全部重试失败后不向用户反馈“没看到图片”`：开启
- `识图失败最大重试次数`：2～3

> `最大重试次数` 不包含首次请求。设为 2 表示最多请求 3 次。
>
> 422、429、鉴权失败等通常不是临时故障，插件默认不会反复请求；超时、连接失败、5xx、空响应会按设置重试。

## 状态命令

```text
/force_caption_status
```
