# Force Image Caption

为 **DeepSeek 等纯文本主模型** 自动补充图片理解。

## 它解决什么问题

普通用法仍然支持：

```text
[图片] @机器人 那这张呢
```

v1.2.0 进一步支持“先发图、下一条再问”的连续对话：

```text
用户：[图片]
用户：第二个是谁？
```

插件会自动完成：

```text
当前图片 / 最近图片
        ↓
视觉模型结合当前问题理解图片
        ↓
<image_caption> 视觉事实 </image_caption>
        ↓
纯文本主聊天模型自然回复
```

## 特点

- 自动处理当前图片、引用图片和多图
- **支持最近图片记忆**：单独发图后，下一条“第二个是谁 / 左边是谁 / 这张呢”等追问仍可识别
- **问题感知识图**：把当前用户问题作为视觉模型语境，不再只做泛化图片描述
- 最近图片默认仅保留 5 分钟，并通过追问判断降低误用旧图的概率
- 仅缓存图片引用，不复制图片二进制；插件重载/重启后缓存自动清空
- 视觉模型临时失败时自动重试，重试次数可配置
- 多图整体失败后可逐张恢复
- 空响应也可自动重试
- 全部重试失败后可静默降级，清理 `[Image Captioning Failed]` 等内部失败标记
- 可禁止主模型向用户回复“没看到图片 / 识图失败”，且不编造视觉内容
- AstrBot 已成功生成图片转述时直接复用，避免重复调用

## 最近图片追问

默认开启 `记住本会话最近图片` 和 `仅在疑似图片追问时复用最近图片`。

插件会优先识别这类追问：

```text
第二个是谁？
左边那个是谁？
这张呢？
图里写了什么？
这个表情包什么意思？
```

为了避免旧图干扰正常聊天，像“今天天气怎么样”这样的普通问题默认不会自动带上最近图片。

如需手动清除本会话图片记忆：

```text
/force_caption_forget
```

## 推荐设置

纯文本主模型建议保持：

- `记住本会话最近图片`：开启
- `最近图片记忆有效期`：300 秒
- `仅在疑似图片追问时复用最近图片`：开启
- `转述成功后移除原图`：开启
- `全部重试失败后移除原图`：开启
- `识图失败时静默处理`：开启
- `全部重试失败后不向用户反馈“没看到图片”`：开启
- `识图失败最大重试次数`：2～3

> `最大重试次数` 不包含首次请求。设为 2 表示最多请求 3 次。
>
> 422、429、鉴权失败、内容审核失败等通常不是临时故障，插件默认不会反复请求；超时、连接失败、5xx、空响应会按设置重试。

## 状态命令

```text
/force_caption_status
```

状态页会显示：图片转述模型、失败重试次数、最近图片记忆开关、记忆有效期，以及当前会话是否已有缓存图片。
