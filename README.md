# Force Image Caption

为 **DeepSeek 等纯文本主模型** 自动补充图片理解。

用户只需要正常发图，例如：

```text
[图片] @机器人 那这张呢
```

插件会自动：

```text
图片 → 视觉模型转述 → 文本描述 → 主聊天模型
```

不需要用户额外说“描述图片”“识别一下”等关键词。

## 特点

- 自动识别当前消息中的图片
- 支持引用消息和多图
- AstrBot 已转述成功时直接复用，不重复调用视觉模型
- 转述结果直接写入本轮 Prompt，降低“转述成功但主模型没看到”的概率
- 支持私聊和群聊

## 使用

1. 主聊天模型可使用 DeepSeek 等纯文本模型。
2. 在 AstrBot 中设置一个支持图片的“默认图片转述模型”。
3. 安装并启用本插件即可。

插件里的“图片转述模型 Provider ID”通常留空即可。

## 状态命令

```text
/force_caption_status
```
